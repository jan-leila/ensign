# Ensign — notes for AI assistants

Controller support mod for FTL (Linux Steam 1.6.13) on Hyperspace. Read `README.md` first.

Rules of the road:
- NixOS: every tool comes from `nix develop` (flake.nix). No system compilers.
- Never modify the real game directory under `~/.steam` except through `tools/install.sh` / `tools/uninstall.sh`.
- The native shim must stay first in `LD_PRELOAD` (it interposes `luaL_newstate`).
- Hyperspace Lua has no `require`; all scripts share one environment under the `ENSIGN` table and are listed in order in `mod/data/hyperspace.xml.append`.
- Struct layouts in `native/third_party/ftl_structs_elf64.h` are layout-only; never retype fields. `OFFSETS.txt` is regenerated by `native/tools/offsets_probe.cpp`.
- Validate UI flows with `tools/run-headless.sh --script tests/<name>.txt` (dev commands documented in `mod/data/ensign/80_dev.lua`). `ENSIGN_TRACE=1` logs every native call.
- Lint Lua with `luacheck mod/data/ensign`; build native with `make -C native`.
