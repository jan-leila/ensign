# Ensign Steam Input files

Action Manifest and default per-controller configurations for FTL (AppID 212680).

- `ensign_actions.vdf`: the Action Manifest (actions, localization, config list).
- `configs/controller_*.vdf`: default bindings per controller type (names as Steam uses them):

  | Class | Controller types | Extras beyond a plain pad |
  |---|---|---|
  | pad | xbox360, xboxone, ps3, switch_pro, switch_joycon_pair, generic | none |
  | ps | ps4, ps5 | touchpad: free cursor + click |
  | psb2 | ps5_edge | touchpad, two back paddles |
  | back4 | xboxelite, legion_go, legion_go_s | four back buttons (paddles) |
  | back2 | switch2_pro (GL/GR), rog_ally, zotac_zone | two back buttons |
  | deck | neptune (Steam Deck), triton (Steam Controller 2026) | two trackpads, four back buttons |
  | sc | steamcontroller_gordon (original Steam Controller) | two pads, two grips |

  Single Joy-Cons have too few buttons for FTL and are left to Steam's own defaults.
- All of these are generated by `tools/gen-steam-input.py` from one table (edit the table, run `python3 tools/gen-steam-input.py`; it re-parses the output and prints a per-controller binding table). Do not hand-edit the .vdf files.

## One action per state-specific verb

Every verb that only makes sense in one UI state is its own action (`room_open`, `detail_toggle_unit`, `slot_retarget`, ...). The mod activates only the verbs relevant to its current state, so several actions are bound to the same physical input. For example A carries `room_open`, `room_send`, `detail_toggle_unit`, ... at once; only the ones the mod currently enables fire.

In the configs this is one activator with several `"binding"` entries in a single `"bindings"` block:

    "button_A" { "activators" { "Full_Press" { "bindings" {
        "binding"  "game_action InGame room_open, Room: open units & doors"
        "binding"  "game_action InGame detail_toggle_unit, Detail: select / deselect unit"
        ...
    } } } }

Consequence for users: rebinding one verb in Steam's configurator does NOT move the others. Remapping `room_open` off A leaves `detail_toggle_unit` etc. on A. To move "the A button" you rebind each verb you care about.

Names are case-sensitive and globally unique across sets.
